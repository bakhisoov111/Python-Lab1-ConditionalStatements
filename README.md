A collection of three beginner-friendly Python projects created to practice programming fundamentals, user input, conditional statements, and problem-solving.
📌 Projects
 1. BMI Calculator
Calculates Body Mass Index (BMI) using a person's height and weight. A simple way to practice numeric input and calculations in Python.
 2. Chinese Zodiac Finder
Finds a person's Chinese zodiac animal based on their birth year. This project explores date-based logic and conditional statements.
3. Birthday Guesser
A fun interactive program that guesses a user's birthday. It demonstrates basic logic and interaction with users.
    Built With
- Python 3
- Beginner-friendly programming concepts
  Getting Started
1. Clone this repository:git clone https://github.com/bakhisoov111/Python-Lab1-ConditionalStatements.git
2. Open the project folder:cd Python-Lab1-ConditionalStatements
3. Run the Python script you want to try:python your_script_name.py
   Replace your_script_name.py with the actual filename in the repository.
